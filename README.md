# AutoRay12 Detailing

Personalized demo website built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Lucide React, next/image and Vercel Analytics.

## Run

```sh
npm install
npm run dev
npm run lint
npm run build
```
